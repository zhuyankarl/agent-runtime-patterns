# Agent Runtime Patterns

让 agent 工作流可验证、可恢复、可追查的通用技能包。

支持设计新流程、实施可靠性改造、审查已有流程，适用于文件、配置表、数据库、API、队列和报告生成。

## 快速使用

将本仓库链接和下面的话发给能够读取仓库文件的 agent：

> 请读取这个仓库的 SKILL.md 及其中按需引用的文件，按 agent-runtime-patterns 的审查模式检查我的项目。先只读分析，报告实际问题、证据和最小改进建议。

仓库地址：https://github.com/zhuyankarl/agent-runtime-patterns

也可以 [下载完整技能包](https://github.com/zhuyankarl/agent-runtime-patterns/archive/refs/heads/main.zip)，解压后让 agent 读取其中的 SKILL.md。若工具支持安装本地 Skill，将解压后的文件夹命名为 agent-runtime-patterns，放到该工具支持的技能目录中。保留 references 目录和相对路径。

## 三种工作模式

| 模式 | 用途 | 交付结果 |
|---|---|---|
| 设计 | 新建重复执行或多阶段任务 | 最小运行结构、运行契约、验收方案 |
| 实施 | 改造已授权的现有流程 | 代码变更、相关验证、恢复信息 |
| 审查 | 核查现有流程的可靠性 | 带证据、影响和优先级的发现 |

## 包含什么

- [SKILL.md](SKILL.md)：技能入口与执行原则。
- [USAGE.md](USAGE.md)：携带方式及可复制的调用提示。
- [运行契约模板](references/runtime-contract.md)：明确输入、输出、权限、状态和恢复。
- [验证矩阵](references/verification-matrix.md)：覆盖预演、重复执行、并发、中断、部分成功及结果未知。
- [适配示例](references/adaptation-examples.md)：按文件、数据库、API、队列和纯读任务选择形态。

## 核心原则

1. 模型做判断，程序执行确定性规则。
2. 候选产物经过程序校验后才能应用。
3. 副作用通过受控入口，预演与正式应用明确区分。
4. 持久保存状态，能够恢复并处理重复执行。
5. 依据产物、回执和验证结果判断成功。
6. 按实际需求增加调度、重试和质量评估。

不要求固定框架、数据库或操作系统；一次性简单任务通常不需要引入新的运行组件。

## 使用示例

**设计配置修改流程**

> 使用 agent-runtime-patterns，为批量配置修改工具制定运行契约。要求能预览差异、检查引用、识别基线变化，并在中断后恢复。

**实施已确认方案**

> 使用 agent-runtime-patterns，按已确认的契约完成可靠性改造及验证。遵守已有授权和项目规则，报告实际结果与未验证范围。

**审查任务执行器**

> 使用 agent-runtime-patterns，检查当前执行器的重复任务处理、并发提交、超时后对账和成功判定。只读审查，逐项给出代码证据。

## 边界

这是技能说明与工程模板包，不是现成的运行引擎。实际效果需要在目标项目中验证；技能本身不会获得额外权限，也不会自动发布、发送消息或提交业务变更。
